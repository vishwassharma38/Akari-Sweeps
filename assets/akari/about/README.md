# Akari about assets

Four unique 346x557 RGB poses in `about_001.png`–`about_004.png`, played
on the About screen. Files `about_005.png`–`about_008.png` are
byte-identical duplicates and are not loaded.

The images are opaque (no alpha); their dark background is part of the
artwork. The loader normalizes them to RGBA for the shared renderer.
