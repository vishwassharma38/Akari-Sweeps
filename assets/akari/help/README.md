# Akari help assets

Four unique 346x557 RGB poses in `help_001.png`–`help_004.png`, played on
the Help screen as the ambient help animation. Files
`help_005.png`–`help_008.png` are byte-identical duplicates and are not
loaded.

The images are opaque (no alpha); their dark background is part of the
artwork. The loader normalizes them to RGBA for the shared renderer.
