# Akari-Sweeps 0.1.1

## What's New

- **Simplified command invocation:** Standardised command usage around the `akari <command>` format, making commands easier to discover and remember. Existing command aliases remain supported for backward compatibility.
- **Refreshed Akari sprites:** Updated the character artwork used throughout the interface for a more consistent visual presentation.
- **Cleaner interface:** Removed unnecessary visual clutter to create a more focused and polished terminal experience.
- **Improved About and Help screens:** Updated both sections with clearer information and more useful command guidance.
- **Administrator permission prompt:** The application now requests administrator privileges during startup so maintenance tasks can run with the permissions they require.
